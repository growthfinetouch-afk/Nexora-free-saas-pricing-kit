# Nexora Free SaaS Pricing Kit

This kit provides a collection of high-converting pricing and checkout components for SaaS applications, built with Tailwind CSS.

## Components Included:

- **Gamified Pricing Grid**: An engaging pricing grid to make plan selection interactive.
- **Interactive Feature Comparison Matrix**: A dynamic matrix for easy feature comparison across different plans.
- **Usage-Based Slider Pricing Calculator**: A flexible calculator for usage-based pricing models.

## How to Use:

1.  **Clone this repository** (or download the files).
2.  **Explore the components** in the `components/` directory.
3.  **View the gallery** by opening `index.html` in your browser to see all components in action.
4.  **Integrate** the HTML and Tailwind CSS into your existing project.
